No. 3 [사전 문제] 애벌레 키우기

[문제 설명]

N x N 의 격자판 위에서 애벌레 키우기 게임이 진행된다.

[Fig. 1] 에서 한 변의 길이 N의 값이 10인 격자판을 확인할 수 있다.

   

 

게임에 참여하는 유저들은 고유한 ID를 가지며 특정 시간(mTime, 단위: 초)에 특정 위치에서(mX, mY) 게임을 시작한다.

초기 애벌레 길이(mLength)가 주어지며, 게임에 참가하게 되면 애벌레가 바라보는 방향은 항상 격자판의 상단을 바라보며 추가된다.

[Fig. 2] 에서 시점이 1초일 때 (2, 3) 위치에 ID가 1이며, 길이가 4인 애벌레가 추가된 것을 확인할 수 있으며, ID가 표시된 위치가 애벌레의 머리이다.



 

게임은 다음과 같은 규칙으로 진행된다.

모든 애벌레는 매초마다 머리가 바라보는 방향으로 1칸씩 전진하며, 만약 몸이 일직선으로 펴져 있는 경우, 바라보는 방향을 시계 방향으로 90도 회전 후에 1칸 전진한다.

[Fig. 3] 에서 시간의 흐름에 따른 애벌레의 위치를 확인할 수 있다.



 

모든 애벌레는 동시에 이동하며, 이동을 마친 후 다음 규칙에 따라 소멸하거나 성장 잠재력을 얻는다.

- 격자판을 벗어난 애벌레는 소멸한다.

- A 애벌레가 B 애벌레에 충돌한 경우, A 애벌레는 소멸하며 B 애벌레는 A 애벌레의 길이만큼 성장 잠재력이 증가한다.

- A 애벌레와 B 애벌레가 서로 머리가 충돌한 경우 두 애벌레는 모두 소멸한다.

- A 애벌레가 B 애벌레에 충돌하고, B 애벌레가 C 애벌레에 충돌한 경우, A 애벌레와 B 애벌레는 모두 소멸하며, C 애벌레는 B 애벌레의 길이만큼만 성장 잠재력이 증가한다.

- 이동 후 위 조건을 만족하는 모든 애벌레들은 동시에 소멸한다.

 

[Fig. 4] 에서 2번 애벌레가 이동 후 격자판 밖으로 벗어나 소멸하는 것을 확인할 수 있다.



 

[Fig. 5] 에서 애벌레들이 이동 후 동시에 소멸하는 것을 확인할 수 있다.



3번 애벌레는 4번 애벌레에 충돌하고 4번 애벌레는 5번 애벌레에 충돌하여 소멸한다.

5번 애벌레는 4번 애벌레의 길이인 4 만큼 성장 잠재력을 획득한다. 성장 잠재력은 애벌레 꼬리 부분의 대괄호 표시를 통해 확인할 수 있다.

6번 애벌레와 7번 애벌레는 서로 충돌하여 두 애벌레 모두 소멸한다.

8번 애벌레와 9번 애벌레는 서로의 머리가 충돌하여 두 애벌레 모두 소멸한다.

 

모든 애벌레는 성장 잠재력이 1 이상인 경우, 매초 이동 시 길이가 1씩 성장하고, 성장 잠재력은 1씩 감소한다.

[Fig. 6] 에서 5번 애벌레가 [Fig. 5] 에서의 충돌 후 시간의 흐름에 따라 성장하는 것을 확인할 수 있다.



 

[Fig. 7] 에서 애벌레들이 이동 후 동시에 소멸하는 것을 확인할 수 있다.



10번 애벌레는 이동 후 격자판을 벗어났고, 11번 애벌레는 이동 후 10번 애벌레와 충돌하여 두 애벌레 모두 소멸한다.

12번 애벌레는 이동 후 충돌이 발생하지 않아 정상적으로 전진한다.

 

게임에 유저들이 계속해서 참여할 때, 특정 시점에 랭킹을 확인할 수 있는 프로그램을 작성해야 한다.

아래 API 설명을 참조하여 각 함수를 구현하라.

 

※ 아래 함수 signature는 C/C++에 대한 것으로 다른 언어에 대해서는 제공되는 Main과 User Code를 참고하라.

 

아래는 User Code 부분에 작성해야 하는 API 의 설명이다.

void init(int N)

각 테스트 케이스의 처음에 호출된다.

격자판 한 변의 길이 N이 주어진다.

초기 시간은 0초부터 시작하며, 이때 격자판 공간 위에는 애벌레가 존재하지 않는다.

 

__Parameters

_____N : 격자판의 한 변의 길이 (10 ≤ N ≤ 2,000)

void join(int mTime, int mID, int mX, int mY, int mLength)

mTime 시간에 ID가 mID이고 길이가 mLength인 애벌레가 (mX, mY) 위치부터 추가된다.

mTime 시간에 모든 애벌레의 이동 및 충돌이 이루어진 후에 추가가 이루어 진다.

애벌레는 항상 격자판의 상단을 바라보는 상태로, 격자판을 벗어나지 않는 위치에 추가된다.

 

애벌레가 추가되는 위치에는 다른 애벌레가 존재하지 않음을 보장한다.

함수 호출 시 전달되는 mID 값은 이전 호출에서 이미 전달된 값이 아님을 보장한다.

 

__Parameters

_____mTime : 현재 시간 (0 ≤ mTime ≤ 10,000)

_____mID : 애벌레의 ID (1 ≤ mID ≤ 1,000,000,000)

_____mX : 애벌레가 추가 된 X 좌표 (0 ≤ mX ≤ N - 1)

_____mY : 애벌레가 추가 된 Y 좌표 (0 ≤ mY ≤ N - 1)

_____mLength : 초기 애벌레의 길이 (3 ≤ mLength ≤ 1,000)

RESULT top5(int mTime)

mTime 시점에 랭킹이 높은 순서로 최대 5마리의 애벌레 ID를 RESULT 구조체에 저장하고 반환한다.

mTime 시간에 모든 애벌레의 이동 및 충돌이 이루어진 후에 애벌레의 랭킹을 반환한다.

랭킹의 기준은 다음과 같다.

① 애벌레의 길이가 긴 애벌레의 랭킹이 더 높다.

② 애벌레의 길이가 같을 경우, ID가 큰 애벌레의 랭킹이 더 높다.

 

반환할 때 저장된 애벌레의 수를 RESULT.cnt에 저장하고 i번째 애벌레의 ID를 RESULT.IDs[I - 1]에 저장한다. (1 ≤ i ≤ RESULT.cnt)

 

격자판 위에 애벌레가 없는 경우 RESULT.cnt에 0을 저장한다.

 

__Parameters

_____mTime : 현재 시간 (0 ≤ mTime ≤ 10,000)

 

__Returns

_____RESULT.cnt : 랭킹이 5위 안에 속하는 애벌레의 수

_____RESUTL.IDs : 랭킹이 5위 안에 속하는 애벌레들의 ID

[제약사항]

1. mTime 값은 이전 함수 호출보다 크거나 같은 값으로 주어진다.

2. 각 테스트 케이스 시작 시 init() 함수가 한 번 호출된다.

3. 각 테스트 케이스에서 join() 함수의 호출 횟수는 최대 400이다.

4. 각 테스트 케이스에서 top5() 함수의 호출 횟수는 최대 300이다.

 

[입출력]

입출력은 제공되는 Main 부분의 코드에서 처리하므로 User Code 부분의 코드에서는 별도로 입출력을 처리하지 않는다.

Sample input 에 대한 정답 출력 결과는 “#TC번호 결과” 의 포맷으로 보여지며 결과가 100 일 경우 정답, 0 일 경우 오답을 의미한다.
